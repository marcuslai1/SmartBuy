# SmartBuy frontend

React + Vite + Tailwind static site that renders `public/phones.json` (generated by the pipeline; don't edit it by hand).
See the [root README](../README.md) for how the data is built, how scores work, and how the site deploys.

Run `npm ci`, then `npm run dev` (served at `/SmartBuy/`), `npm run lint`, `npm run build`.
